시험 문항

시험 요약집

시험 문항을 차시별로 정리해, 요약집만 봐도 정답을 고를 수 있게 만듭니다.

  • 문제와 정답을 "○○은 ○○이다" 한 문장으로 정리
  • 빈칸( ) 문항은 빈칸에 정답을 넣은 문장으로
  • "잘못된 것은?" 문항은 올바른 보기만 번호 목록으로
  • 정답 키워드는 굵은 파란색으로 표시
진행단계평가와 최종평가('2-1. 평가(시험)') 문항을 씁니다.
과제 문항

과제요약집

과제 문항마다 모범답안을 예시 여러 개(기본 20개)로 정리합니다.

  • "정답 및 해설"의 모범답안 내용을 그대로 사용
  • 예시마다 목록 모양과 항목 표기를 바꿔서 정리
  • 문장 끝은 "~합니다/~입니다"로 통일
기본은 문장을 그대로 두고 모양만 바꿉니다. 예시 20개를 서로 다른 답으로 받으려면 문항별 "Claude에서 작성하기" 버튼을 누르면 됩니다.
과제 문항

과제 가이드

학습자가 AI로 과제를 하고 제출하는 방법을 단계별로 안내합니다.

  • 문항별 문제 원문을 상자에 담아 정리
  • 접속 → 붙여넣기 → 저장 → 업로드 순서 안내
  • 화면 캡처를 올리면 단계 아래에 넣어 줌
모범답안과 답안 예시는 넣지 않습니다.

세 문서 모두 자료에 없는 내용은 추가하지 않습니다.

바로 만들기

만들 문서를 고르고 과정개요서(엑셀)를 올리면 Word 파일을 만들어 드립니다. 파일은 서버로 보내지 않고 이 화면에서만 처리됩니다.

Claude로 예시를 서로 다른 답으로 쓰기 (선택)

아래 결과는 모범답안 문장을 그대로 두고 모양만 바꾼 것입니다. 예시마다 다른 답으로 받으려면 문항별로 ① "Claude에서 작성하기"를 눌러 Claude(claude.ai) 창을 열고 보내기 → ② Claude 답 아래 복사 버튼으로 답을 복사 → ③ 칸에 붙여넣고 "결과에 반영"을 누르세요. 반영된 문항만 바뀝니다. Claude에 로그인되어 있어야 합니다.

** **로 감싼 부분은 Word에서 굵은 파란색이 됩니다. 진행단계평가는 "● ", 최종평가는 "◆ "로 시작하고, 두 평가 사이의 "---"는 Word에서 실선이 됩니다.

  • 진행단계평가 시트와 최종평가 시트('2-1. 평가(시험)')의 문항, 보기, 정답을 읽어 같은 규칙으로 정리합니다. 진행단계평가가 먼저, 실선 아래에 최종평가가 이어집니다. AI가 쓰는 것이 아니라 정해진 규칙으로 바꿉니다.
  • 소제목은 문제 문장에서 자동으로 만들어서 어색할 수 있어요. 위 칸에서 바로 고치세요. 원문 오타는 고치지 않으니 확인해 주세요.
  • 과제요약집과 과제 가이드는 과제 시트('평가(과제)')의 평가문항과 정답 및 해설을 읽습니다. 과제요약집의 예시는 기본적으로 모범답안 문장을 그대로 두고 목록 모양과 항목 표기만 바꿉니다. 예시마다 다른 답으로 받으려면 결과 위의 "Claude에서 작성하기"로 Claude 창을 열어 맡긴 뒤 답을 붙여넣으세요. 이 홈페이지가 직접 AI를 부르거나 파일을 보내지는 않습니다. 프롬프트는 내가 연 Claude 창에만 들어갑니다.

만들기 전에 확인해 주세요

준비할 자료

  • 평가 엑셀(과정개요서) .xlsx 파일
  • 시험 요약집: 진행단계평가 시트와 시험 시트('2-1. 평가(시험)')에 문항, 보기, 정답
  • 과제요약집·과제 가이드: 과제 시트('평가(과제)')에 평가문항, 정답 및 해설
  • 과제 가이드 캡처(선택): AI 첫 화면, 과제 업로드 화면, 최종 제출 화면
  • 과정명은 '훈련내용' 시트에서 자동으로 가져옵니다

내려받기 전에 확인하세요

  • 안내된 문항 수가 엑셀의 문항 수와 같은지
  • "○○은 ○○이다" 문장이나 "~합니다" 끝맺음이 어색하지 않은지
  • 과제 가이드에서 단계 문구와 그림이 다른 쪽으로 갈라지지 않았는지
  • 원문 오타와 띄어쓰기 (자동으로 고치지 않습니다)

궁금한 점을 먼저 확인해 보세요

어떤 파일을 올려야 하나요?

평가 엑셀(과정개요서)을 올려 주세요. 시험 요약집은 시험 시트의 문항·보기·정답을, 과제요약집과 과제 가이드는 과제 시트의 평가문항·정답 및 해설을 읽습니다.

어떤 형식으로 받나요?

Word(.docx) 파일로 내려받습니다. A4 용지 기준이며 정답 키워드는 굵은 파란색으로 표시됩니다.

자료에 없는 내용도 들어가나요?

아니요. 엑셀에 있는 문항과 정답만 사용합니다. AI가 새로 쓰지 않고 정해진 규칙으로 정리합니다.

과제요약집 예시는 서로 내용이 다른가요?

기본 결과는 모범답안 문장을 그대로 두고 목록 모양과 항목 표기만 예시마다 바꿉니다. 예시 20개를 서로 다른 답으로 받으려면 문항별 "Claude에서 작성하기" 버튼으로 Claude 창을 열어 보내고, Claude 답을 다시 붙여넣어 "결과에 반영"을 누르세요. Claude 답은 모범답안에 없는 내용이 섞이지 않았는지 꼭 확인해 주세요.

과제 가이드의 그림은 어떻게 들어가나요?

"문제 붙여넣기"와 "결과물" 그림은 자동으로 그려 넣습니다. AI 첫 화면, 과제 업로드 화면, 최종 제출 화면은 직접 올린 캡처를 넣고, 올리지 않으면 글로만 안내합니다.

올린 파일은 어디로 가나요?

어디로도 보내지 않습니다. 파일은 이 화면 안에서만 처리되고 서버에 저장되지 않습니다.
